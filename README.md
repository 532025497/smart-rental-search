# 智能租房搜索

按工作地点、通勤时间和预算筛选地铁可达区域，并可通过 LLM 将租房帖子提取为结构化房源。

## 本地运行

1. 安装 Python 3.9 或更新版本。
2. 复制配置示例并填写自己的高德 Web 服务 Key：

   ```bash
   cp .env.example .env
   ```

3. 运行：

   ```bash
   ./run.sh
   ```

4. 打开 `http://127.0.0.1:5050`。

首次启动会在 `.venv` 创建隔离环境并安装依赖。macOS 可以双击 `start.command` 启动。

## 配置

`GAODE_API_KEY` 是搜索通勤可行域的必填项。`DEEPSEEK_API_KEY` 或 `LLM_API_KEY` 是可选项：未配置时仍可查看可达地铁站和地图，但不会提取房源帖子。

不要将 `.env` 或任何 API Key 提交到 GitHub。

## 说明

项目包含北京地铁站缓存，可直接用于北京搜索。切换城市时，系统会调用高德 API 获取并缓存该城市的站点数据。
